# Testing Skill

Use the narrowest meaningful test set first, then broaden verification when justified.

Required areas from the SRS:
- unit
- integration
- API
- database
- eligibility
- policy
- RAG
- agent
- security
- E2E
- performance
- recovery

Eligibility matrix must cover exact thresholds, below/above thresholds, backlog boundaries, degree/department/year mismatches, missing data, missing requirements, missing/conflicting policy, unavailable RAG, and invalid policy versions.

Agent tests must verify authorization, tool choice, grounding, no hallucinated criteria, no unauthorized mutation, and no eligibility override.
